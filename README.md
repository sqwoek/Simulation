# 🌍 Predator & Herbivore Simulation

A turn-based 2D simulation of a world with 🐯 predators, 🐇 herbivores, and static objects (🌱 grass, 🌳 trees, 🪨 rocks).

- 🐯 Predators hunt herbivores and move up to **2** cells per turn.
- 🐇 Herbivores search for and eat grass, moving up to **1** cell per turn.
- Creatures can move and interact only horizontally and vertically.
- Grass and herbivores are automatically respawned when their population becomes too low.

Enjoy watching the ecosystem evolve in real time!

This project was implemented as part of the [Java Backend Learning Course by Sergey Zhukov](https://zhukovsd.github.io/java-backend-learning-course/).
